What this system is

apk2source is an automated reverse-engineering & asset-extraction pipeline (industry terms: RE pipeline, binary-to-source reconstruction, asset ripping pipeline). It takes an Android distribution container and walks it down to first-class source assets.

  1. Acquire — download .apk/.apks/.xapk/.apkm/.aab, resumable, sha256-verified, cached.
  2. Unpack — normalise any split-APK container into one merged APK tree.
  3. Detect — fingerprint the engine (Unity / Unreal / Godot / libGDX / Cocos / Defold) from evidence, not names.
  4. Device cache — install on an emulator, perform the first run, snapshot-diff the app data dirs to isolate what the app downloaded at runtime.
  5. Decompile — UnityPy for asset bundles, AssetRipper for project reconstruction, jadx/apktool for Java+resources, Il2CppDumper for IL2CPP.
  6. Spine — content-sniff skeleton .json/.skel, .atlas and texture pages; pair them; export.
  7. Publish — push to source_spine and game_source (sparse clone, optional Git LFS).
